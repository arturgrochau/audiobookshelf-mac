# Contributing

Feedback, bug reports and pull requests are welcome.

- **Bugs and ideas:** open an issue with the template. For security problems, see [SECURITY.md](SECURITY.md).
- **Building:** `./build.sh` builds and installs the app, `./test.sh` runs the unit tests (macOS 15+, Xcode Command Line Tools).
- **Scope:** the app follows the Audiobookshelf web client's layout and wording, and focuses on listening. Changes that keep it native, fast and uncluttered are the easiest to merge.
- **Style:** match the surrounding code. `xcrun swift-format` is the formatter.
- **Pull requests:** keep them focused, and make sure `swift build` and the tests pass. CI checks both.
